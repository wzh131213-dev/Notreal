# AI Token Optimization Skill

AI Token 优化 Skill，旨在帮助 AI 大模型（LLM）和 Agent 在 Prompt 工程、上下文管理、代码生成和结构化输出中减少 Token 占用。

## 文件说明
- `SKILL.md`：Token 优化 Skill 主文件（包含 YAML 格式 Name 与 Description）
- `SKILLS/token-optimization.md`：格式同步 Skill 文档
- `skills/token-optimization/SKILL.md`：Skill 包标准路径
- `token-optimization.zip` / `token-optimization.skill`：包含 `SKILL.md` 的 Skill 压缩包
